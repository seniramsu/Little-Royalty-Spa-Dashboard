Create `src/lib/booking-window.ts` exporting a pure function:
```ts
export type Urgency = "low" | "medium" | "high"
export interface NextActionPrompt { message: string; urgency: Urgency; daysUntil: number }
export function getNextActionPrompt(now: Date = new Date()): NextActionPrompt
```
Implementation:
  1. Import `toZonedTime` from `date-fns-tz` and `differenceInCalendarDays`, `startOfDay`, `addMonths`, `setDate`, `setHours`, `setMinutes`, `setSeconds` from `date-fns`.
  2. Convert `now` to `America/Chicago` via `toZonedTime(now, "America/Chicago")`.
  3. Compute the next target datetime: the 1st of next month at 09:00 CST. Special case: if today (in CST) is the 1st and the current CST hour is < 9, target today at 09:00 CST instead.
  4. `daysUntil = differenceInCalendarDays(target, zonedNow)`.
  5. Branching:
      - Day 1 (CST) + hour < 9: `{ message: "Booking window opens today at 9am CST — get ready!", urgency: "high", daysUntil: 0 }`
      - Day 1 (CST) + hour >= 9: `{ message: "Booking window is open now — check your inquiries", urgency: "high", daysUntil: 0 }`
      - `daysUntil <= 5`: `{ message: \`Booking window opens in ${daysUntil} days — plan your campaign\`, urgency: "medium", daysUntil }`
      - else: `{ message: \`Next booking window opens in ${daysUntil} days\`, urgency: "low", daysUntil }`

Create `src/lib/booking-window.test.ts` with a minimal Node test (or a script runnable via `tsx`) exercising:
  - `new Date("2026-04-13T12:00:00Z")` (mid-month) -> urgency "low" or "medium", daysUntil matches calendar math.
  - `new Date("2026-05-01T13:00:00Z")` (May 1, 8am CDT) -> "opens today at 9am", urgency "high".
  - `new Date("2026-05-01T15:00:00Z")` (May 1, 10am CDT) -> "open now", urgency "high".
  - `new Date("2026-03-08T10:00:00Z")` (DST spring-forward day) — days until April 1 is a stable integer.
  - `new Date("2026-11-01T13:00:00Z")` (DST fall-back day + Nov 1 boundary) — correct "opens today" branch.
